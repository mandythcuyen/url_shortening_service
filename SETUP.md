# URL Shortening Service Setup Guide

This project is built on **Ruby on Rails 8.1.3** and uses **Ruby 4.0.6**, **PostgreSQL** for the database, and **Redis** for caching and Action Cable. It can be run in three ways: locally, with Docker, and in production on AWS Lightsail.

---

## General Requirements

| Tool | Version / Notes |
|------|-----------------|
| Ruby | 4.0.6 (see `.ruby-version`) |
| Rails | ~> 8.1.3 |
| PostgreSQL | 17 recommended, 9.5+ supported |
| Redis | Any stable version |
| Docker | To run with Docker or deploy to production |
| Node.js | Not required; this is a pure API backend |

Get the `RAILS_MASTER_KEY` from `config/master.key` before running any environment.

## 2. Running with Docker (production-like)

The Docker stack includes PostgreSQL, Redis, the Rails app (Puma through Thruster) and a Caddy reverse proxy with automatic TLS.

### 2.1. Configure environment variables

```bash
cp .env.production.example .env.production
chmod 600 .env.production
```

Fill in the following values:

```env
RAILS_MASTER_KEY=<content of config/master.key>
HOST=http://localhost
APP_DOMAIN=localhost
POSTGRES_USER=url_shortening_service
POSTGRES_PASSWORD=<optional password>
POSTGRES_DB=url_shortening_service_production
```

> With `APP_DOMAIN=localhost`, Caddy will serve plain HTTP on `:80`.

### 2.2. Build and run

```bash
docker compose up --build -d
```

### 2.3. Check status

```bash
docker compose ps
docker compose logs -f web
```

### 2.4. Access the app

```bash
curl -I http://localhost/up
```

### 2.5. Stop and remove containers

```bash
docker compose down
```

### 2.6. Stop and remove containers including data

```bash
docker compose down -v
```

## 3. Running in production (AWS Lightsail)

### 3.1. Prerequisites

- An AWS account and a Lightsail instance running Ubuntu 22.04 LTS.
- A domain or subdomain pointed at the instance.
- `gh` CLI installed and logged in.
- `config/master.key` available on your local machine.

### 3.2. Install Docker on the server

```bash
sudo apt-get update
sudo apt-get install -y docker.io docker-compose git
sudo usermod -aG docker $USER
newgrp docker
```

### 3.3. Create swap (required for the 1GB plan)

```bash
sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
```

### 3.4. Clone the repo and configure

```bash
cd ~
git clone https://github.com/mandythcuyen/url_shortening_service.git
cd url_shortening_service

cp .env.production.example .env.production
chmod 600 .env.production
nano .env.production
```

Fill in:

- `RAILS_MASTER_KEY`: copy from your Mac.
- `HOST`: `https://short.mandyseeyoo.com` (or your chosen domain).
- `APP_DOMAIN`: `short.mandyseeyoo.com`.
- `POSTGRES_PASSWORD`: generate randomly with `openssl rand -hex 16`.

### 3.5. First start

```bash
docker login ghcr.io -u mandythcuyen -p <GITHUB_TOKEN>
docker compose pull web
docker compose up -d
```

> `GITHUB_TOKEN` needs `read:packages` scope. You can skip `docker login` if the image is public.

### 3.6. Configure DNS

Add an A record:

```
short  A  <lightsail-static-ip>
```

### 3.7. Verify

```bash
curl -I https://short.mandyseeyoo.com/up
```

Expected result: `HTTP/2 200`.

### 3.8. Automatic deployment

When pushing to `main`, the `.github/workflows/ci.yml` workflow will:

1. Run brakeman, bundler-audit, rubocop and rspec.
2. Build a `linux/amd64` image and push it to `ghcr.io/mandythcuyen/url_shortening_service`.
3. SSH into the server, pull the new image and run `docker compose up -d`.

### 3.9. Common operational commands

```bash
# View logs
docker compose logs -f web

# Backup database
mkdir -p ~/backups
docker compose exec db pg_dump -U url_shortening_service url_shortening_service_production \
  > ~/backups/db_$(date +%Y%m%d_%H%M%S).sql
```

## Security Notes

- Never commit `config/master.key`, `.env`, `.env.production`, or `cookies.txt`.
- `config/master.key` is the only secret needed to decrypt `config/credentials.yml.enc`.
- Only open ports 22, 80 and 443 in the production firewall; never expose 3000 or 5432.
